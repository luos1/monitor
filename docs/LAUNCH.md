# 아이패드미러 출시 검증

검증 기준: 2026-10-04. MacBook 원본 `luos1/monitor`를 기준으로 개발했습니다. 사용자 미커밋 자료와 맥미니의 다른 프로젝트는 보존합니다.

## 제품과 빌드 3

- iPad/iPhone iOS 17+ 송신 앱과 Broadcast Extension, macOS 14+ 무료 수신 앱입니다. Mac은 시간 제한과 구매/복원 UI가 없습니다.
- 하나의 앱에서 기기 언어가 한국어이면 한국어, 그 밖의 언어이면 영어를 표시합니다. 앱·확장·Mac의 표시 이름도 현지화합니다.
- 앱과 확장은 버전 1.0, 빌드 3입니다. Mac은 버전 1.0.0, 빌드 3이며 arm64와 x86_64를 포함합니다.
- 사용자가 지정한 최종 아이콘을 적용했습니다. 원본 아이콘 편집은 별도 백업을 보존하며, 필요한 크기와 불투명 RGB 여부를 확인했습니다.
- 기존 전체 창 보기 구조를 유지하고 ‘사용법’, ‘앱 전체 크기로 보기’ 글자를 검정으로 표시합니다.
- 연결마다 인증 상태를 분리하고 오래된 소켓의 콜백을 버립니다. 화면 회전, 방송 상태와 종료 요청을 처리하며 사용 시간은 방송 중 갱신합니다.

## 완료한 검증

- Swift 테스트 24개, 실패 0개: 페어링·암호화, 실제 소켓의 암호화 JPEG 송수신, 오래된 연결 무효화·종료·재연결, 방송 상태, 사용 시간·보상·권한 정책, 언어 선택, 보상 광고 캐시 만료를 검증했습니다.
- Xcode 로컬 StoreKit 테스트 8개, 실패 0개: 두 상품 조회, 구매 취소, 영구 사용 구매·복원·환불, 개발자 응원 구매·복원, 승인 대기, 상품 조회/구매/복원 오류와 복구를 확인했습니다. 실제 결제나 Apple Sandbox 계정 구매는 수행하지 않았습니다.
- 한국어·영어 화면과 일본어·프랑스어의 영어 대체 표시를 검증했습니다. 실제 OS 언어를 맞춘 iPad/iPhone 화면은 별도로 시각 검사하며, 구매 창의 하단 잘림을 수정했습니다.
- 실제 iPad mini 6에서 USB로 암호화 화면을 Mac에 수신했습니다. 사용자 직접 관찰과 Mac 수신 프레임 수·크기를 기록했습니다. 사용자의 화면 내용은 검증 기록에 저장하지 않았습니다.
- 실제 iPad Google 테스트 보상 광고를 끝까지 시청·닫은 뒤 추가 시간이 0에서 정확히 3,600초로 증가했습니다. 후속 읽기에서도 3,600초로 유지되었고 실제 화면의 남은 시간은 1시간 27분이었습니다. SDK 완료 처리에도 중복 콜백 방지 가드가 있습니다.
- 구성 preflight 통과. Release archive/IPA의 실제 운영 광고 ID와 버전·서명·업로드 결과는 산출물 검증 기록에서 별도로 확인해야 합니다.

## 광고와 개인정보

- Google Mobile Ads 12.14.0, UMP 3.1.0을 고정합니다. Debug는 Google 샘플 광고, Release는 기존 운영 광고 ID입니다.
- UMP `canRequestAds` 이후에만 광고를 요청하며 필요한 개인정보 설정 버튼을 제공합니다. QA `-SkipAds`는 광고와 추적 요청을 생략합니다.
- 광고 캐시는 55분 이후 폐기합니다. 보상은 실제 SDK 보상 콜백과 닫힘 완료 뒤 한 번만 지급합니다. 취소/표시 실패에는 보상을 지급하지 않습니다.
- 광고 SDK manifest의 7개 데이터 유형과 연결·추적·목적 선언을 별도 근거표로 전달했습니다. 이것만으로 실제 계정의 광고 설정이나 법적 응답을 추측하지 않습니다.
- 자체 StoreKit 구매·권한은 기기에서 검증하고 저장합니다. 구매 내역을 자체 서버나 광고 SDK로 보내는 코드는 없습니다.

## 외부 등록과 남은 검증

- 기존 App Store 앱 `com.raccoonmerchant.ipadmirror`와 버전 1.0을 사용합니다. 기존 업로드 빌드 2는 VALID로 확인했으며 이번 변경 소스의 빌드 3과 구분합니다.
- 두 Non-Consumable 상품 ID와 사용자가 정한 개발자 응원 가격을 유지합니다. 심사용 구매 화면은 공개 마케팅 화면과 구분해 전달합니다.
- 공개 스크린샷은 권한·ATT·방송 시작 시스템 팝업을 제외하고 실제 연결한 미러링 화면만 실사용 원본으로 인정합니다. 가짜 연결 프레임이나 필기 기능 UI를 만들지 않습니다.
- Apple Pencil 필기는 외부 iPad 앱의 화면을 미러링하는 사용 사례입니다. 강의·회의 전달은 외부 회의 앱에서 Mac 수신 창을 공유하는 방식이며 자체 필기/회의 통합 기능은 없습니다.
- Mac 공용 로컬 검수 ZIP을 만들었지만 현재 MacBook에 Developer ID Application 서명 인증서가 없습니다. 임시 서명 패키지는 Gatekeeper 검사를 통과하지 않아 검증된 공개 설치 링크로 제공할 수 없습니다. 새 자격증명은 별도 승인 후 처리합니다.
- 실기기 Wi-Fi, 회전·방송 종료/재연결의 추가 사용자 검수와 실제 Apple Sandbox 구매·복원은 완료하지 않았습니다. 자동 테스트 결과와 혼동하지 않습니다.
- 개인정보 응답, 등록 문구·판매 지역·심사 연락처와 제출 작업은 웹 담당이 처리합니다. 은행/세금/약관/계약 관련 사용자 보류 사항을 임의로 변경하지 않습니다.
- archive 성공, IPA 업로드, Apple 처리 완료, 심사 제출, 승인·출시는 각각 별도 결과입니다. 최종 기록은 선택한 IPA의 SHA-256과 실제 App Store 상태를 사용합니다.

## 프로젝트 범위 Ruflo

기존 공식 Ruflo를 `scripts/ruflo-local.sh`로 이 프로젝트에서 사용했습니다. 자동 daemon과 funnel을 끄며 다른 프로젝트의 경로 고정 MCP를 재사용하지 않습니다. MCP 도구 조회와 로컬 메모리 호출을 확인했습니다. Ruflo의 정적 분석은 Swift를 지원하지 않아 Swift/Xcode 검증을 근거로 사용합니다. 메모리 DB·비밀 자료·사용자 개인 화면은 커밋하지 않습니다.
