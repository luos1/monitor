## 광고와 개인정보 확인 범위

- Google Mobile Ads 12.14.0, UMP 3.1.0을 고정합니다. Debug는 Google 샘플 광고, Release는 기존 운영 광고 ID입니다.
- UMP `canRequestAds` 이후에만 광고를 요청하며 필요한 개인정보 설정 버튼을 제공합니다. DEBUG 전용 QA `-SkipAds`는 광고와 추적 요청을 생략합니다. 새 제출 소스 5ae19c0b와 Release IPA 13·PKG 3은 이 옵션과 호출부를 제외했습니다. 과거 공개 직접 배포 Mac 4에는 이 결과를 적용하지 않습니다.
- 광고 캐시는 55분 이후 폐기합니다. 보상은 실제 SDK 보상 콜백과 닫힘 완료 뒤 한 번만 지급합니다. 취소/표시 실패에는 보상을 지급하지 않습니다.
- 광고 SDK manifest의 7개 데이터 유형과 연결·추적·목적 선언을 별도 근거표로 전달했습니다. 이것만으로 실제 계정의 광고 설정이나 법적 응답을 추측하지 않습니다.
- 자체 StoreKit 구매·권한은 기기에서 검증하고 저장합니다. 구매 내역을 자체 서버나 광고 SDK로 보내는 코드는 없습니다. 앱 자체 개인정보 파일의 수집 목록은 비어 있으며, iPad 광고 SDK의 원본 manifest가 SDK의 7개 수집 유형을 선언합니다. Required Reason API 선언과 광고 SDK 파일은 보존했습니다. Apple의 수집 정의상 기기에서만 처리한 데이터와 Apple이 수집한 데이터는 구분합니다.
- 실제 빌드 4 IPA의 앱 manifest는 추적 true와 빈 도메인 배열을 함께 포함했습니다. 이는 Apple TN3181에서 금지하는 조합입니다. 추적 true는 유지하고 고정 SDK와 제출 실행파일에서 확인한 두 광고 호스트를 선언했습니다. 추적하지 않는 확장·Mac에서는 빈 도메인 키를 제거했습니다. 구조 검사와 실제 빌드 4를 이용한 회귀 검증을 통과했으며 SDK 원본은 변경하지 않았습니다. 근거와 추론 범위는 [개인정보 파일 기술 검증](PRIVACY-MANIFEST-VALIDATION.md)에 기록했습니다.

## 제출 이력과 남은 검증

- 기존 App Store 앱 `com.raccoonmerchant.ipadmirror`와 버전 1.0을 유지합니다. 과거 빌드 4는 업로드·VALID 처리·버전 선택 뒤 ITMS-91064가 보고된 이력이 있습니다. 현재 재제출 기록은 위 iOS 13·Mac Store 3입니다. 과거 오류 수정이나 재제출 완료만으로 Apple의 최종 승인 또는 5.6 판단 원인 해소를 주장하지 않습니다.
- 두 Non-Consumable 상품 ID와 사용자가 정한 개발자 응원 가격을 유지합니다. 심사용 구매 화면은 공개 마케팅 화면과 구분해 전달합니다.
- 공개 스크린샷은 권한·ATT·방송 시작 시스템 팝업을 제외하고 실제 연결한 미러링 화면만 실사용 원본으로 인정합니다. 가짜 연결 프레임이나 필기 기능 UI를 만들지 않습니다.
- Apple Pencil 필기는 외부 iPad 앱의 화면을 미러링하는 사용 사례입니다. 강의·회의 전달은 외부 회의 앱에서 Mac 수신 창을 공유하는 방식이며 자체 필기/회의 통합 기능은 없습니다.
- 공개 직접 배포 Mac 4의 서명·공증·배포는 이미 기록돼 있습니다. 새 Store 3의 대체 설치본으로 안내하지 않으며, 심사자의 동반 앱 설치 경로는 여전히 미확인입니다.
- 새 13/3 조합의 실기기 네트워크 미러링, 회전·방송 종료·재연결, 실제 광고·UMP/ATT와 Apple Sandbox 구매·복원은 완료하지 않았습니다. 과거 USB·광고 시험이나 로컬 자동 테스트와 혼동하지 않습니다.
- 새 Store 3의 연결 화면과 일치하는 한국어·영어 스크린샷 및 스토어 안내 확인이 남아 있습니다. 기존 USB 연결 이미지는 네트워크 전용 Store 빌드의 근거로 사용하지 않습니다.
- 등록 문구·개인정보 응답·판매 지역·심사 연락처는 콘솔 기록과 대조해야 합니다. 은행/세금/약관/계약 관련 사용자 보류 사항은 유지합니다.
- archive·업로드·처리·재제출과 승인·공개는 별도 결과입니다. 다음 상태 확인에서는 실제 App Store Connect 상태와 수동 출시 결과를 새 시각과 함께 기록해야 합니다.

## 과거 프로젝트 범위 Ruflo

기존 공식 Ruflo를 `scripts/ruflo-local.sh`로 이 프로젝트에서 사용했습니다. 자동 daemon과 funnel을 끄며 다른 프로젝트의 경로 고정 MCP를 재사용하지 않습니다. MCP 도구 조회와 로컬 메모리 호출을 확인했습니다. Ruflo의 정적 분석은 Swift를 지원하지 않아 Swift/Xcode 검증을 근거로 사용합니다. 메모리 DB·비밀 자료·사용자 개인 화면은 커밋하지 않습니다.
