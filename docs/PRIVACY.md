# 아이패드미러 개인정보 처리방침

시행일: 2026-08-17
문의: intheluos@gmail.com

아이패드미러는 iPad 화면을 같은 사용자의 Mac으로 보내는 앱입니다. 화면 내용은 개발자 서버로 전송되지 않습니다.

## 수집하는 정보

- 사용 시간: 무료 60분과 연장 시간을 기기 로컬(`UserDefaults`)에 저장합니다.
- 로컬 네트워크/USB: Mac이 같은 네트워크 또는 USB의 iPad를 찾기 위해 사용합니다.
- 기기 이름: Bonjour 안내에 표시되는 이름입니다.

계정, 위치, 연락처, 분석 SDK, 광고 식별자는 현재 버전에서 수집하지 않습니다.

## 화면 데이터

ReplayKit이 캡처한 프레임은 iPad에서 Mac으로만 전달됩니다. 클라우드 업로드, 녹화 저장, 제3자 공유는 하지 않습니다.

## 광고와 결제

출시 후 전면 광고와 인앱 결제를 연결할 수 있습니다. 그때 광고/결제 제공자의 정책이 추가로 적용되며, 이 문서와 스토어 설문을 함께 갱신합니다.

## 보관

사용 시간 기록은 앱을 삭제하면 함께 사라집니다.
