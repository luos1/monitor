# 아이패드미러 개인정보 처리방침

최종 수정: 2026-10-04
문의: intheluos@gmail.com

아이패드미러는 iPad 화면을 같은 사용자의 Mac으로 보내는 앱입니다. 화면 내용은 개발자 서버로 전송되지 않습니다.

## Mac 배포판별 연결과 데이터 처리

Mac App Store 수신 버전은 같은 사용자의 iPad를 로컬 네트워크의 Bonjour로 찾고 암호화된 화면을 받습니다. 이 버전에는 USB 직접 연결과 `usbmuxd` 기기명·시리얼 조회 코드가 포함되지 않습니다. USB 케이블만 연결해서는 미러링할 수 없습니다.

기존 공증 다운로드 수신 버전은 로컬 네트워크와 USB 직접 연결을 지원합니다. 아래 USB 식별 정보 설명은 USB를 지원하는 다운로드 버전에 해당합니다.

Mac 수신 앱에는 제3자 광고·분석 SDK가 포함되지 않습니다. Mac 앱 자체가 화면, 분석, 광고, 충돌·진단 데이터를 개발자 또는 제3자 수집 서버로 보내는 기능은 없습니다. iPad 송신 앱에 포함된 광고 SDK의 처리는 아래 별도 설명을 따릅니다.

## 수집하는 정보

- iPad 사용 시간: 무료 60분과 연장 시간을 기기 로컬(`UserDefaults`)에 저장합니다.
- 로컬 네트워크/USB: Mac App Store 버전은 로컬 네트워크만 사용합니다. USB 지원 다운로드 버전은 같은 네트워크 또는 USB의 iPad를 찾기 위해 사용합니다.
- 기기 별칭: Bonjour에는 실제 기기명이나 연결 코드 대신 방송마다 생성한 임의 별칭을 표시합니다.
- USB 식별 정보(USB 지원 다운로드 버전): Mac이 로컬 `usbmuxd`를 통해 연결된 iPad를 구분하기 위해 기기명과 시리얼을 조회합니다. 이 정보는 Mac 내부의 기기 매칭에만 사용하며 개발자 서버로 전송하지 않습니다.

화면 전송 코드에는 사용자 계정 가입, 연락처 접근, GPS 위치 요청 기능이 없습니다. 광고 SDK의 데이터 처리는 이와 별개입니다. iPad 송신 앱에 포함된 Google Mobile Ads 12.14.0의 privacy manifest와 [Google의 SDK 데이터 공개 안내](https://developers.google.com/admob/ios/privacy/data-disclosure)에는 대략적 위치, 기기 식별자, 광고 및 앱 상호작용, 진단 정보가 신고되어 있습니다. 대략적 위치에는 IP 주소로 추정하는 위치가 포함될 수 있습니다.

광고 요청은 Google UMP의 요청 가능 상태를 확인한 뒤 이루어집니다. 필요한 동의 양식과 개인정보 설정 옵션은 UMP가 제공합니다. iOS 추적 허용은 선택이며, 추적을 거부해도 화면 전송 기능은 사용할 수 있습니다. 추적 거부가 광고 SDK의 모든 데이터 처리를 중단한다는 의미는 아닙니다. 광고 제공자의 처리는 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.

## 화면 데이터

ReplayKit이 캡처한 프레임은 사용자가 연결한 Mac으로 전달됩니다. 이 앱의 화면 전송 기능에는 개발자 서버 업로드나 녹화 저장 기능이 없습니다. Mac은 iPad에 표시된 8자리 연결 코드로 인증되며, 전송 중인 화면 프레임은 ChaCha20-Poly1305로 암호화되고 위변조 여부를 검증합니다. 사용자가 별도의 회의 앱에서 Mac 창을 공유하는 경우 그 공유는 해당 회의 앱이 처리합니다.

## 광고와 결제

iPad 앱은 Google AdMob 리워드 광고와 배너 광고를 사용합니다. 리워드 광고를 끝까지 보면 사용 시간 60분이 연장됩니다. 광고 제공자의 정책은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.

영구 사용과 개발자 응원은 Apple 인앱 결제로 처리됩니다. 결제 정보는 Apple이 처리하며 이 앱은 카드 번호를 저장하지 않습니다. 응원 상품을 구매하면 영구 사용도 함께 해제됩니다.

Mac 수신 앱은 시간 제한과 별도 구매 없이 무료입니다. Mac 앱에는 AdMob 광고와 인앱 결제가 없습니다.

## 보관

사용 시간과 광고 연장 기록은 기기에 저장합니다. Apple의 구매 기록과 Google 광고 서비스의 보관은 각 제공자의 정책에 따르며 이 앱의 로컬 기록과 구분됩니다.
